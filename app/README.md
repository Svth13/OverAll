# Веб-приложение OverAll

Веб-интерфейс (FastAPI) поверх скриптов парсинга Google Таблицы стажёров:
логику ноутбуков `Парсинг_v4.ipynb` и `Парсинг_снепшот_v2.ipynb`
вынесено в модуль `app/core.py`, поверх него построено веб-приложение `app/main.py`.

## Возможности

| Страница | Что делает |
|---|---|
| `/` — Главная | Статус подключения, загрузка данных из таблицы в кэш сессии, сводка по снепшотам |
| `/report` — Отчёт для оплаты | Выбор года/месяца → формирование `exports/payroll_report_ГГГГ_ММ.xlsx` (листы «Ежедневный_отчет» и «Сводка_за_месяц»), просмотр таблиц в браузере и скачивание Excel |
| `/snapshots` — Снепшоты | Создание дневного среза (`snapshots/snap_ГГГГ-ММ-ДД.xlsx`), ведение `history.csv`, сравнение с предыдущим снепшотом и журнал изменений (`добавлен / удален / изменен`) |

Дополнительно:
- `GET /job/{id}` — статус фоновой задачи;
- `GET /download/<файл>` — скачивание отчётов и снепшотов;
- `GET /docs` — OpenAPI-документация API.

Все трудоёмкие операции выполняются в фоновых задачах (страница сама опрашивает прогресс).

## Запуск

```bash
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
# или: python -m app.main
```

Открыть http://localhost:8000

## Требования к данным

- В корне проекта должен лежать файл `Credentials.json`
  (ключ сервисного аккаунта Google, см. README основного проекта);
- Сервисный аккаунт должен иметь доступ на чтение к таблице
  `SPREADSHEET_ID` (настраивается в `app/core.py`);
- Структура листов и индексы столбцов совпадают с ноутбуками.

## Структура

```text
app/
├── __init__.py
├── core.py          # бизнес-логика: парсинг, payroll-отчёт, снепшоты (из ноутбуков)
├── main.py          # FastAPI-приложение: маршруты, фоновые задачи, шаблоны
├── templates/       # base.html, index.html, report.html, snapshots.html
└── static/          # style.css, app.js
exports/             # сгенерированные payroll-отчёты (Excel)
snapshots/           # снепшоты, history.csv, changes_log.csv
requirements.txt
```
